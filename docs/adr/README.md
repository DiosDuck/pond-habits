# Architecture Decision Records (ADR)

An ADR records one decision: the context, the decision and the consequences. All ADRs below have the status "Accepted" on 2026-11-20.

## How to change a decision

1. Do not edit the decision text of an accepted ADR.
2. Write a new ADR. Set the old ADR status to "Superseded by ADR NNNN".
3. Add the change to [privacy.md](../privacy.md) if it changes the privacy baseline.
