# Today (home page)

The Today page is the first page after login.

## Content

Each feature has a card. Each card links to its page.

- Credits balance
- Start a pomodoro
- Tasks due today and overdue tasks
- Habits to tick today
- Nutrition progress bars for today

## Navigation

- On mobile, other pages show a bottom tab bar. The bar has a "Today" tab.
- The Today page does not show the bottom tab bar. The cards are the menu.
- The Today header has links to Settings and, for admins, Admin.
- The design session can change these points.

## Growth

Each new feature adds its card to the Today page.
