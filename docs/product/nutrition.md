# Nutrition

## Goals

- Daily goals for calories, protein, fat and carbs. Optional: fiber, sugar, water.
- Each goal is a minimum, a maximum or a range. Example: protein min 120 g, calories max 2200.

## Entries

- Manual entry of the values per food entry.
- Entries are grouped by meal: breakfast, lunch, dinner, snack.
- The user can save foods to a personal "saved foods" list and use them again.

## Credits

- All daily goals met: +10.
- A limit exceeded: -5.

## Backlog

- Lookup in a public food database (for example Open Food Facts) and barcode scan.
- Recipes made from many ingredients.
